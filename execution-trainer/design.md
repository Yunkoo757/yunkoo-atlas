# Execution Trainer 设计约定

直接采用 frontend-design-judgment 的 Atlas v1.4.25 / 42947005 通用资产：中性微靛暗色、Inter 及系统中文回退、语义表面和文字、间距、字段与按钮配方。文件已复制到 design/，运行不读取 Skill 或 Atlas 源码。字体许可证随资源保留。

布局适配为独立单窗、单列 680px 表单轨道；默认窗口 420×480，最小 380×440。没有侧栏。主工作面使用 pane；区块透明，仅分隔线；24px 区块间距，28px 内容内边距。标题 20/28/600，主计数使用现有 title2 24px，元数据 12/18/400，普通行 13/20/400。普通按钮和字段 32px，唯一主计数动作 36px。数字使用等宽数字特性，不全局使用等宽字体。

DONE、MISSED 用中性文字表达事实，不映射盈亏色，不奖励、不谴责。历史和时间记录折叠。创建页集中说明不可逆约定。名称最长 80 字并换行。焦点补全为可见描边，减少动效可关闭状态过渡。

不迁移 Atlas 的交易字段、资料库、路由、快捷键、侧栏和业务模型。独立 Electron 主进程，只暴露读取、创建、完成一次三个 IPC 动作。

减法版：删除品牌栏、重复 REPS 标题、已完成/剩余常驻行。今日承诺合成单行；天数与达标率合成单行；每日历史与完成时间统一收进记录入口。剩余次数移至记录内。创建页数字字段并排，原有约束与完整历史保留。

动效：沿用 100ms 状态、150ms 页面进入、220ms 内容变化及 ease-out-quart。按钮按压下移 1px，页面进入位移 4px，计数位移 3px；进度使用左侧原点 scaleX，不改变布局。记录展开使用原生 details 高度过渡。写盘确认后反馈，动画不锁定操作；计数保留历史展开状态。系统减少动态效果时停用全部过渡及 Web Animations，并支持设置即时切换。

记录展开时根滚动槽始终保留，滚动条宽 8px 并消费 scrollbar Token，防止高度动画触发滚动条后横向重排；关闭浏览器滚动锚定，避免展开过程自动修正位置。

窗口改为无系统边框，顶部 32px 同色拖动栏提供最小化与关闭，控件区域不可拖动。删除内层重复窗格边框。计数点击不设冷却、不过滤双击；异步队列逐次持久化，按钮节点在计数更新中保留，避免鼠标按下/松开间重建节点导致漏计。队列写入失败时停止剩余请求并明确提示。关闭按钮等待当前队列处理结束。
