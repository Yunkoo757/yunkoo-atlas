A FEW THINGS TO KNOW

常见问题

Trader Atlas 适合谁？

希望持续记录交易、整理执行、建立个人案例库的交易者。可以从一笔记起。

支持哪些平台？

Windows 和 macOS 桌面客户端。安装包以发布页为准。

页面里的软件窗口来自哪里？

首屏工作台按桌面客户端同一套视觉规则用 HTML 搭成，侧栏可切换交易日志、统计分析、周期复盘、案例库、复盘组合器、随机复盘和随记。数据来自隔离的 Yunkoo 示例资料库。下方功能画廊仍使用真实截图。都只作功能展示，不代表收益，也不使用你的本地资料库。

我可以先学习，再下载吗？

可以。打开顶部「使用指南」，按步骤了解记录、复盘和案例沉淀。
