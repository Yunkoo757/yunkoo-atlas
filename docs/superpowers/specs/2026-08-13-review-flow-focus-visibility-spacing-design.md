# 复盘文档流、焦点高光与日期间距收敛设计

日期：2026-08-13  
状态：已确认，待实施计划  
适用平台：Windows 客户端、macOS 客户端

## 1. 背景

桌面视觉收敛后，实际页面仍暴露出三类割裂感：

1. 交易详情把“复盘正文”处理成醒目的表单分区标题，紧接着又出现“盘面摘要”，形成两层标题竞争；正文和大图虽然属于同一份笔记，视觉上却像拼接的模块。
2. 全局 `:focus-visible` 会在侧栏条目或整个主内容框架外绘制高饱和紫色轮廓。应用又会在焦点恢复与错误恢复时主动聚焦工作区，因此不使用 Tab 的用户也会看到大面积高光。
3. 交易日志的月份分组条直接贴住列标题，缺少垂直呼吸区；虚拟列表与吸顶结构让普通外边距不能安全解决该问题。

本次只做针对性收敛，不重构编辑器、交易列表或焦点管理体系。

## 2. 已确认决策

- 复盘正文采用“克制文档流”，不改成结构化卡片表单。
- 新增“显示键盘焦点高光”偏好，默认关闭。
- 关闭高光只影响可见轮廓，不移除焦点、键盘操作、焦点陷阱、焦点恢复或输入反馈。
- 月份分组条与列标题之间增加 `8px` 间距。
- 仍只适配 Windows 与 macOS 桌面客户端。

## 3. 复盘正文视觉结构

### 3.1 信息层级

普通交易详情不再把“复盘正文”显示成带底部分隔线的强标题。视觉顺序改为：

1. 交易标的标题；
2. 必要时显示紧凑的复盘状态与“完成复盘”动作；
3. 盘面摘要导语；
4. 正文、清单、引用与图片，按同一文档流连续排版；
5. 复盘追记。

“复盘正文”继续作为编辑器的可访问名称，供辅助技术和自动化定位使用，但不再作为重复的视觉标题。

案例详情保留“案例沉淀”的业务语义。来源复盘与案例自有沉淀仍需可辨认，不能因为普通交易去标题而混为同一份内容。

### 3.2 状态与动作

待复盘交易仍需显示状态和“完成复盘”动作，但两者组成轻量工具行：

- 工具行不使用贯穿正文宽度的分隔线；
- 状态文字使用次级层级，主按钮保持现有语义；
- 已复盘且没有待处理状态时，不为正文保留空标题行；
- 结果缺失或冲突提示继续位于正文之前，不改变闭环逻辑。

### 3.3 盘面摘要

现有 `data-review-context` 数据结构和可选固定能力保留，避免改写历史 HTML。其视觉改为文档开篇导语：

- “盘面摘要”使用弱标签，不与页面标题竞争；
- 摘要与首张图片之间保留 `16px`；
- 摘要内部段落维持紧凑节奏；
- 不增加卡片底色、外框或阴影；
- 开启现有摘要固定偏好时可继续 sticky，但固定态与普通文档流保持同一视觉表面；
- 关闭摘要固定偏好时恢复普通文档顺序，不改变文本与图片内容。

### 3.4 正文和图片

- 正文维持适合长读的行高与块间距，不增加人工分栏。
- 图片仍可利用正文可用宽度，保持缩放查看能力。
- 图片与前后文字至少保留 `16px` 垂直间距；连续图片之间使用同一节奏。
- 不给图片增加厚重卡片容器；仅保留现有轻边框与圆角。
- 空正文仍显示原有占位提示，点击空白区继续可将光标置于文末。

## 4. 键盘焦点高光偏好

### 4.1 设置入口

在“设置 → 显示偏好”新增“交互反馈”区，提供开关：

- 名称：`显示键盘焦点高光`
- 说明：`使用 Tab 或键盘导航时，以轮廓标出当前控件。关闭后仍可使用全部键盘操作。`
- 默认值：关闭

偏好字段命名为 `showKeyboardFocusRings: boolean`，归入 `DisplayPrefs` 并沿用现有持久化、导入导出与 `normalizeDisplay` 路径。

旧快照没有该字段时必须规范化为 `false`。导入非法类型时同样回退为 `false`。

### 4.2 应用方式

应用根节点根据偏好暴露单一状态属性，例如：

```html
<div class="ui-app-frame" data-keyboard-focus-rings="off">
```

焦点高光样式只在偏好开启时生效。关闭时：

- 全局 `:focus-visible` 紫色 outline 不显示；
- 组件自定义的焦点 outline 与焦点 ring shadow 同样不显示；
- 不改变 hover、pressed、selected、active、error、warning、saving 等状态；
- 输入框正在编辑时的背景和边框反馈保留，因为它表达输入状态，不属于 Tab 轮廓；
- 侧栏当前页面背景、筛选选中态和分段控件选中态保留。

不得通过移除 `tabIndex`、阻止 Tab、取消程序聚焦或跳过焦点恢复来实现视觉关闭。

### 4.3 可访问性边界

默认关闭是明确的产品偏好，但能力必须完整保留：

- 开关开启后，侧栏、主内容、菜单、列表行、日期选择器、弹窗和编辑器工具全部恢复当前可见焦点语法；
- Modal、菜单、日期选择器的焦点陷阱与 Escape 返回不受影响；
- Skip link 仍可获得焦点并执行跳转；其是否显示轮廓服从同一偏好，但跳转能力不变；
- 自动化必须分别覆盖开和关两种状态。

本节在用户偏好层面取代 `2026-08-12-desktop-visual-system-convergence-design.md` 中“焦点始终可见”的默认呈现要求；焦点行为合同本身继续有效。

## 5. 交易日志日期分组间距

月份分组条与吸顶列标题之间增加 `8px` 垂直间距。实现必须由虚拟行容器承担，而不是给内部 sticky 分组条添加普通 `margin-top`：

- header 虚拟行包含顶部 padding；
- virtualizer 测得的 header 高度必须包含该 padding；
- 首个分组、后续分组和吸顶分组使用同一几何规则；
- 滚动吸顶时不得跳动、遮住列标题或产生透明点击空洞；
- 分组条左右边距、圆角、高度和新增按钮位置保持不变。

## 6. 数据与兼容

- `showKeyboardFocusRings` 随资料快照保存，并进入现有导入导出合同。
- 旧资料缺字段时默认为 `false`，不需要一次性数据迁移。
- 复盘正文不修改已保存 HTML；只调整外层结构和 CSS 呈现。
- `data-review-context` 的解析、切换与历史兼容保持不变。
- 日期间距不改变交易排序、分组 key、折叠状态或虚拟列表数据。

## 7. 测试与验收

### 7.1 测试驱动顺序

1. 先为 `DisplayPrefs` 默认值与规范化写失败测试。
2. 再为显示设置开关和根节点状态写失败的浏览器测试。
3. 再为焦点高光开启/关闭写真实样式失败测试，确认焦点仍实际移动。
4. 再为复盘文档层级和图片间距写失败的设计/浏览器测试。
5. 最后为月份 header 虚拟行的 `8px` 间距、测量和吸顶稳定性写失败测试。

### 7.3 完成门槛

- 定向单元、设计合同与浏览器测试通过；
- `pnpm test`、`pnpm build:app` 通过；
- Windows 渲染器在焦点高光开/关两种状态各留一组证据；
- 核心详情与交易日志在 Windows 100%/125%/150% 缩放下无裁切；
- macOS arm64/x64 构建与既有平台证据门不回退；
- 页面错误、控制台错误和横向溢出均为零。

## 8. 非目标

- 不重新设计整个详情页属性栏。
- 不改变复盘完成条件、模板内容或自动保存机制。
- 不删除键盘导航或辅助技术语义。
- 不新增手机、平板或浏览器端适配。
- 不改变交易列表的字段列、排序或分组业务逻辑。
