# Trader Atlas 设置页字体一致性设计

## 目标

在不改变设置页功能、文案含义、字段顺序和布局结构的前提下，收敛 Windows 与 macOS 桌面客户端中全部设置入口的字体层级。设置页应与今日工作台、仪表盘、周复盘和交易详情共享同一套页面标题、区块标题、行标题、辅助说明与注释角色，避免辅助文字和局部身份信息抢占主视觉层级。

适配范围为 960–1920px 桌面窗口，仅覆盖 Windows 与 macOS 客户端。

## 问题结论

设置页现有页面主标题使用 20px 的 `--type-page-title-size`，与其他核心页面一致，应当保留。视觉偏大的主要原因不是主标题，而是设置域内大量辅助说明使用了 15px 的 `--type-body-size`，以及个人资料预览名称复用了 20px 页面标题角色。

具体表现包括：

- 页面说明、区块说明和设置组说明达到 15px，与页面正文同级，超过设置导航、字段名称和列表主信息的 13px。
- 个人资料预览名称使用 20px，与“个人资料”页面标题形成两个同级主标题。
- 数据、显示、标签、风险和资料库相关区域对辅助说明的字号选择不完全一致。
- 多数具体字段已经采用 13px 主信息与 12px 辅助信息，说明现有方向正确，只需统一设置域的语义映射。

## 字体层级

设置页统一采用以下五层字体角色：

1. 页面主标题：20px，使用 `--type-page-title-size`。仅用于每个设置入口顶部的唯一 `h1`。
2. 区块标题与字段主信息：13px，使用 `--type-section-title-size` 或 `--type-row-size`。区块标题使用 semibold，字段与列表主信息保持既有 row 字重。
3. 页面说明、区块说明与字段辅助信息：12px，使用 `--type-metadata-size` 和 `--type-metadata-line-height`。
4. 控件文字：13px，继续由共享 `Button`、输入框、导航和行控件消费 `--type-row-size`，不在设置页私自覆盖。
5. 注释、短标签和弱辅助信息：11px，使用 `--type-caption-size`。

15px 的 `--type-body-size` 只保留给需要连续阅读的正文、重要警告正文或突出数据，不再用于普通设置说明。数据值若需要强调，可保留 15px，但其标签和说明仍分别使用 12px 与 11px。

## 组件与样式边界

### 共享设置骨架

`SettingsLayout.css` 负责设置域的全局语义：

- `.settings-page-title` 保持页面标题角色。
- `.settings-page-desc` 改为 metadata 角色。
- `.settings-section-title` 保持 section title 角色。
- `.settings-section-desc` 改为 metadata 角色。
- 设置导航继续使用 row 角色。

### 页面专用样式

各设置面板只调整与上述语义冲突的文字：

- 个人资料：预览名称降为正文级 15px，区块提示保持 12px。
- 显示偏好：区块说明从 15px 降为 12px；行标题与行说明保持 13px/12px。
- 标签管理：区块说明从 15px 降为 12px。
- 数据与资料库：普通说明统一 12px；任务标题与数据主值保持 13px 或必要的 15px。
- 风险、策略、快捷键、品种、复盘起稿和软件更新：沿用共享骨架，并清理局部放大的普通说明。

不修改弹窗、富文本编辑器、交易数据视图和其他非设置域的字号。

## 设计变量策略

本次不修改 `tokens.css` 中的全局字号值，也不新增只服务于某个页面的裸字号。全部调整复用既有 `--type-*` 语义角色，避免全局字体缩小导致交易详情、周复盘正文和弹窗说明可读性下降。

设置页样式中不得新增裸 `font-size` 数值。历史 `--fs-*` 别名可在未触及区域保留，但本次修改的选择器优先使用 `--type-*` 角色。

## 交互与业务边界

- 不修改 React 状态、Zustand 数据、持久化、快捷键、风险规则、导入导出和更新逻辑。
- 不改变按钮、输入框、开关、列表与弹窗的尺寸和点击区域。
- 不改变文案含义、ARIA 文义、字段顺序或导航结构。
- 字号调整不得引入文本截断、关键内容折行或横向溢出。

## 验证方案

### 自动契约

新增设置页字体层级设计契约，至少验证：

- 页面主标题仍消费 `--type-page-title-size`。
- 页面与区块说明消费 `--type-metadata-size`。
- 个人资料预览名称不再消费 `--type-page-title-size`。
- 显示、标签和数据页的普通说明不再消费 `--type-body-size`。
- 修改的设置页选择器只使用既有语义字体变量。

### 回归验证

- `pnpm qa:design`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm qa:desktop-visual --renderer`

桌面视觉矩阵重点检查全部十个设置入口在 960、1440、1920px 下的标题层级、说明密度、字段可读性、折行和溢出。代表截图同时与今日工作台、仪表盘和周复盘对照，确认页面主标题保持一致，而辅助信息不再抢占层级。

## 完成标准

- 每个设置入口只有一个视觉上的 20px 页面主标题。
- 普通页面说明、区块说明和字段辅助信息统一为 12px。
- 区块标题、字段名称、列表主信息和控件文字稳定在 13px。
- 11px 仅用于短标签、注释和弱辅助信息。
- 960–1920px 桌面窗口无新增折行、截断或横向溢出。
- 全部测试、类型检查、构建、设计契约和桌面视觉矩阵通过。
