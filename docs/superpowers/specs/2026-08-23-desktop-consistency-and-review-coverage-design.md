# 桌面端页面一致性与随机复盘覆盖修复设计

## 背景

本次改动解决四类已经在真实 Windows 资料库中复现的问题：

1. 历史实盘把自身使用的 `liveStage` 与 `tab` 查询参数显示成“未支持的筛选条件”。
2. 随机复盘只纳入已完成复盘且有正文的实盘与模拟盘记录，导致 181 笔模拟盘仅有 4 笔进入候选池；当前 62 条候选由 23 个案例、35 笔实盘和 4 笔模拟盘组成。
3. 周复盘左侧记录栏过窄，阶段名称、状态和日期发生逐字换行，破坏信息层级。
4. 历史实盘与设置页面的容器、字号、边框和间距密度不一致，历史实盘尤其存在多层厚重卡片嵌套。

适配范围仅为 Windows 与 macOS 桌面客户端，不考虑浏览器、手机或平板布局。

## 目标与非目标

### 目标

- 历史实盘不再把页面路由状态误报为未知筛选。
- 随机复盘的来源开关与候选数量符合用户直觉，并能解释每一次过滤。
- 周复盘、历史实盘、随机复盘设置弹窗和设置页面使用一致的桌面端字号与间距层级。
- 在保留现有 React、CSS、路由和状态管理结构的前提下做局部升级，不重写应用框架。

### 非目标

- 不改变案例的到期、掌握度和案例范围算法。
- 不改变历史阶段归属、绩效计算和风险事实。
- 不重做侧栏、顶栏或所有业务页面。
- 不引入新的 UI 框架、字体库或运行时依赖。

## 方案

采用“局部统一设计系统”方案：修复数据和路由根因，同时让四个相关界面复用现有 `type-*`、间距、颜色和控件 token。避免只做局部遮挡，也避免扩大为全应用重构。

## 数据与路由逻辑

### 历史实盘查询参数

历史实盘列表复用通用交易工作台，但 `liveStage` 和 `tab` 属于历史实盘页面的路由状态，不是交易筛选条件。通用筛选器应把它们视为已知的非筛选参数：

- 不生成“未支持的筛选条件”标签；
- 不计入筛选数量；
- 清除交易筛选时保留当前历史阶段和标签页；
- 其他真正未知的参数仍显示为可移除条件，避免静默忽略损坏的保存视图。

### 随机复盘候选池

三类来源采用清晰分离的规则：

- 案例记录：继续受案例范围、到期范围、掌握度和阶段来源控制。
- 实盘交易：选中来源后，纳入所选阶段内所有已结束或已错过且未删除的记录，不再要求 `reviewStatus` 为已复盘。
- 模拟盘：选中来源后，纳入所有已结束或已错过且未删除的模拟记录，不受实盘阶段来源限制，也不再要求 `reviewStatus` 为已复盘。
- “仅含有效图文”关闭时，不以正文是否存在为过滤条件；开启时，三类来源统一要求存在有效文本或图片内容。

候选数量必须由同一个 `buildReviewSessionPool` 结果计算，设置弹窗预览、开始按钮与实际生成轮次不得使用不同口径。以当前真实资料库为验收样本：仅启用模拟盘且关闭有效图文限制时为 181 条，开启后为 178 条；数量随资料库变化实时更新，不在代码中硬编码。

## 视觉设计

### 周复盘

- 左侧记录栏由 148px 增至约 220px，并在较窄桌面窗口下保持可用的最小宽度。
- 每一条记录采用“周标识/日期 + 阶段名称 + 状态点”的稳定结构；日期和短状态不得逐字换行。
- 当前周使用轻量选中底色与单一强调色，不使用额外厚边框。
- 主内容标题、进度、章节编号和章节标题对齐到统一基线，正文仍保持阅读型内容宽度。

### 历史实盘

- 阶段选择从大块卡片降为紧凑横向选项：名称为主信息，日期为次信息，选中态仅使用浅底色和细边界。
- 标签页与阶段选择共享一个轻量导航区，减少顶部空白和重复分隔线。
- 概览、周复盘和风险页移除“背景页 + 外层大卡 + 内层卡”的三层嵌套；页面主体使用阅读轨道和分段线，仅在指标组、异常提示等需要边界的区域使用容器。
- 实盘记录与关联案例继续复用标准列表/看板，不改变行信息密度和操作方式。

### 随机复盘设置

- 保留现有弹窗结构，缩小来源选项的垂直高度和视觉重量。
- 来源标题使用正文强调级，说明使用辅助文字级；选中态使用统一强调色细边框和弱底色。
- 候选数量靠近过滤条件显示，并明确它是“当前设置”的实时结果。

### 设置页面与字号

相关设置界面统一为四级文本：

1. 页面标题：`--type-page-title-*`。
2. 分组标题：`--type-section-title-*`。
3. 正文、导航和控件：`--type-row-*` 或 `--type-body-*`。
4. 描述、状态和元信息：`--type-metadata-*`。

本次清理相关页面中混用的局部 `--fs-sm`、`--fs-mini` 和裸字号，不改变全局字体，也不通过整体缩放掩盖布局问题。数据数字继续使用等宽数字特性。

## 状态与错误处理

- 未知查询参数继续显示可移除提示；只有页面明确拥有的路由参数被排除。
- 随机复盘某个来源为空时，数量准确显示为零，不回退到其他来源。
- 设置弹窗取消时不提交草稿；应用设置后才影响下一轮。
- 已开始的随机复盘轮次继续保持稳定快照，不因候选池实时变化而中途插入记录。
- 页面空状态、加载状态和键盘焦点行为保持现有契约。

## 测试与验收

### 自动化测试

- 路由测试：`liveStage`、`tab` 不产生未知筛选标签，真正未知参数仍可见且可移除。
- 随机池单元测试：实盘与模拟盘不再依赖 `reviewStatus`；有效图文开关是唯一内容过滤器；案例规则不变。
- 随机复盘浏览器测试：设置预览数量、实际轮次和来源组合一致。
- 周复盘与历史实盘设计测试：关键桌面宽度、无逐字换行、轻量容器层级和字号 token 契约稳定。
- 类型检查与受影响回归测试全部通过。

### 真实资料库只读验收

- 历史实盘页面不显示两枚“未支持的筛选条件”。
- 当前资料库仅启用模拟盘时显示 181 条；开启有效图文限制后显示 178 条。
- 周复盘左栏中的“本周”、阶段名、状态与历史日期在常用桌面窗口宽度下可正常阅读。
- 历史实盘顶部高度降低、外层大卡弱化，并与交易日志和设置页保持一致的信息密度。

## 发布

完成针对性测试、类型检查和 Windows 打包后生成新的 x64 NSIS 安装包。macOS 代码路径保持兼容，但本轮不在 Windows 环境中生成 macOS 安装包。
