# 移除判断台与复盘组合器

按产品定位撤销判断台改造，并删除判断台、复盘组合器及其专属功能链路。实现位于 Trader-Atlas；本轮未操作真实 Chrome、已安装客户端、真实交易资料库或订单，未提交、推送或发布。

## 删除范围

- 删除两个页面及 CSS、判断台收录/排序/训练/历史组件、组合器步骤/规则/草稿/生成引擎及其专属测试。
- 移除侧栏、命令面板、快捷键动作与范围、默认配置、设置页、图片菜单、详情来源绑定和回收站判断引用保护。
- 移除 Store、快照类型、持久化字段、附件盘点域及导入导出中的两模块专属状态。
- 删除官网展示舞台、教学站 `/guide/composer/`、对应入口、独立 QA 脚本和前轮判断台设计/验收文档。历史通用审计报告保留，并注明模块已退役。

交易录入组件 `TradeComposer`、案例库、随记、随记转案例、复盘起稿模板、周期复盘、随机复盘与交易计算保留。它们不属于复盘组合器。

## 旧数据边界

只保留 `src/storage/retiredSnapshotDomains.ts` 与 `electron/library/retiredSnapshotDatabase.ts` 的最小兼容处理：忽略两个旧字段及其已知导航配置，识别旧包中已知路径的专属附件，并清理新写出的数据库副本。没有保留页面、模型、训练、生成器或状态机。

- v13/v14/v15 资料库及旧 JSON/Web/native 归档可读取，旧模块状态不会恢复或写回。
- 旧状态损坏不妨碍交易、案例、周复盘和随记加载。
- 共享图片继续按现行业务引用计入；仅在旧模块中引用的导入图片可被精确跳过，不能借此放过其他无关孤立附件。
- 启动兼容读取不主动删除已有物理图片。真实库和历史备份本轮均未执行迁移或清理。
- Electron 与 IndexedDB 中心 writer 以及离线资料库编辑器均剥离旧字段，避免它们被通用扩展字段透传写回。
- 新备份、新归档和私有恢复候选均不再携带旧状态；清理只修改候选的 `meta.snapshot`，不改来源库、原包、历史备份、schema、revision、其他 meta 或附件索引。无退役内容时保留原数据库字节。

## 取消、失败与中途重开复验（2026-11-13）

使用全新临时 userData 和全新临时资料库，经产品 UI 导入上一轮校验和一致的合成归档作为基线。原生文件选择只指向任务临时目录，没有打开真实资料库、已安装客户端或真实 Chrome。已有基线为 TRD-1（盈亏 20、R 2）、CAS-1、置顶随记及合成原图；本轮新增 TRD-2、CAS-2、另一条随记及第二张合成原图。

发现并修复四类保护缺口：

1. **新建表单未提交时正常退出**：退出屏障只保存 Store 和编辑器草稿，原先未覆盖 React 内存中的新建表单。现先完成已有保存任务，再检查当前表单是否修改；未提交时取消退出，复用 `ModalShell compact` 和现有按钮，继续使用后原文字、截图仍在。已成功保存关闭的表单不会误拦截退出。没有自动生成交易或新增持久草稿格式。
2. **随记转换重复生成**：局部 React 状态不能覆盖慢 flush、离开再进入，以及快 flush 已完成但旧控件尚未退出的重复点击。现使用按随记 ID 共享的短期转换租约，案例和交易共用；成功后保留到旧编辑页退出，失败后释放，未来主动重新进入仍可再次转换。整个转换复用现有 pending-operation 屏障，切库和退出会等待完成，不增加新存储协议。
3. **来源删除后旧值复活**：慢保存期间来源随记被删除，旧转换任务曾回退到闭包中的旧对象生成记录。现只接受保存完成后仍存在的来源，不再使用旧值回退；不存在则停止、释放租约，不生成交易或案例。
4. **原生导入失败后继续使用**：部分安装失败回滚并重开资料库后，writer 未接管新生命周期，且 UI 留有已消费的恢复预览。现恢复 writer 会话并使旧预览失效，重新选择归档可重试；重开或接管结果不确定时仍暂停写入，不能用旧快照覆盖。用户提示不暴露内部异常或绝对路径，技术原因只进入脱敏日志。

本轮不改设计 token、公共焦点合同、交易字段、财务计算和已退役模块边界。新增退出确认沿用既有紧凑弹窗，保留顶层焦点圈定、Esc 和返回原表单，不以失焦或移除键盘功能绕过保护。

| 原生操作 | 最终结果 |
| --- | --- |
| 新建交易的取消、关闭 X、Esc，再继续编辑 | 未保存文字和同一张可解码 PNG 预览都保留；没有创建记录 |
| 带图未保存时正常退出，再继续使用 | 退出被拒绝，仍可编辑、保存或明确放弃；连续保存只生成一个 TRD-2 |
| 明确放弃后重新打开 | 新表单为空；已有交易、原随记和原图不变 |
| 随记最后输入后立即双击转案例 | 仅生成一个 CAS-2；来源随记和最后正文保留 |
| 原生导入／导出文件选择取消，及有效恢复预览取消 | 不执行资料库替换，不生成交易、案例或归档 |
| 损坏 ZIP 与格式错误 JSON | 提示失败，既有完整快照、附件索引、manifest 和原图内容不变 |
| 数据库已替换、活动附件已清空时注入一次附件复制 EIO | 完整回滚到四条原有记录、两条随记和两张原图；失效预览关闭，输入可继续保存 |
| 回滚后继续编辑，再重新选择有效归档并双击确认 | 写入会话正常；恢复成功，字段和原图一致，无重复记录，来源归档校验和不变 |

随机复盘原有轮次队列／游标存于 `sessionStorage`，筛选条件存于 `localStorage`。因此完整退出后新进程回到复盘首页属于既有规则，不代表交易资料丢失；本轮没有新增跨进程续轮功能，也没有把前轮“离开页面后返回”描述为完整重启续轮。正常退出的草稿保存不等同于断电或强杀能保存最新 RAM 输入；本轮未作此保证。
