# Atlas 资料库编辑器

使用桌面 Chrome / Edge 打开同目录的 index.html，无需联网或启动 Atlas。请保留整个文件夹。

1. 点击「打开资料库」，选择包含 journal.db、manifest.json、attachments 的目录。
2. 通过左侧分类浏览；搜索后可选择当前结果，批量迁入模拟盘。迁移保留交易 ID、正文、截图、标签；解除实盘阶段及周复盘直接引用，冻结历史证据保留。
   表头复选框支持全选／取消当前筛选结果，「取消全选」清除全部选择。交易列表支持按策略筛选、批量设置策略；右侧可按策略名称下拉选择。标签预置和错误标签预置支持直接新增，多个名称用逗号分隔，自动去空去重。
3. 右侧提供完整 JSON 编辑，点击「应用编辑」才会进入待保存版本。错误会被 Atlas 校验器拦截。切换项目前需要处理尚未应用的草稿。
4. 周复盘可单独清空。实盘日志都迁入模拟盘后即可重置实盘阶段，同时清空周复盘及阶段风险记录。案例无需迁移，仍保留在案例库，仅解除旧阶段关联；案例正文、截图、标签及其他内容保留，标签预置、随记和策略也保留。
5. 点击「校验」，再「另存新资料库」，选择一个空目录。成功后使用 Atlas 打开新目录。

源目录只申请读取权限。修改暂存在内存，关闭页面会丢失；撤销可以回退本次会话内的修改。导出使用本页载入并编辑的独立副本，不合并 Atlas 后续修改，也不会因源库再次保存而中断。导出会检查附件尺寸与引用，先保存编辑后的数据库与恢复记录，再逐文件复制和比对附件，最后写入并回读 manifest。只有显示「导出完成」才可在 Atlas 打开。失败目录可能留有部分文件；本页修改仍保留，可另选空目录重试。新版创建的失败目录可在编辑器中重新打开以恢复编辑数据，缺失附件会阻止导出，仍需从原附件目录补齐。

新库具有新 libraryId，不复制设备同步队列、备份或临时文件。保留全部登记附件，不自动回收。支持当前 Atlas schema 13 及 Atlas 解码器可升级的历史版本，拒绝未来版本。完整 JSON 编辑面向熟悉字段的操作；不会执行正文中的脚本或加载外部图片。

构建：在项目根目录运行 `node tools/atlas-data-editor/build.mjs`，产物为 `release/atlas-data-editor`。构建时复用 Atlas 数据契约和 tokens.css，运行时与 Atlas 解耦。
