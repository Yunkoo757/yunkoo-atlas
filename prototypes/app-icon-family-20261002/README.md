# Atlas 应用图标系列

设计基线为当前 build/icon.svg：底板 #121318，主体 #E7E7EB，图标强调色 #737BDD，512 网格、16 外留白、112 底板圆角和 8% 白色边框。图标强调色采用实际品牌资源；应用控件强调色仍为 tokens.css 的 #5e6ad2。

- 聚焦 · Focus：专注、计时、轻量工作台。
- 层叠 · Stack：知识库、资料管理、笔记。
- 联结 · Link：同步、连接、协作工具。
- 取景 · Frame：截图、视觉素材、创作工具。
- 流转 · Flow：自动化、任务编排、流程工具。
- 归藏 · Vault：文件归档、本地备份、安全存储。

svg/ 是带底板的应用图标；glyph/ 是透明背景的同版主体。所有文件都是独立 SVG，无字体、外部图片、脚本、滤镜或外部依赖。主体色需在白色背景使用时替换为深色。

index.html 提供下载与 16/24/32/48 像素缩放预览；preview.png 为实际浏览器截图。小尺寸目前是同母版缩放，正式打包时应另做 16/20/24/32 像素光学校正，并生成目标软件的 ICO/ICNS。当前交付为 SVG 设计资产，未替换 Atlas 图标。
