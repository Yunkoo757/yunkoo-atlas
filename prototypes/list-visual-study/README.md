独立 HTML，不修改正式客户端、全局 token 或真实资料库。默认打开 index.html?variant=B；底部“查看原 B”可比较第一轮 B。双击 index.html 可离线运行，重建命令为 node prototypes/list-visual-study/build.mjs。

## 当前 B：细节打磨

已撤回用户否定的 920px 限宽、142px 品种列和分组／筛选改版。列表恢复原来满宽网格，字号、行高、列位置、月份底色和筛选胶囊都与原 B 一致。

本轮只改策略／标签槽：统一 6px 内容间距；策略按钮使用 24px 点击高度，常态无轮廓，悬停与键盘聚焦显示轻背景和轮廓；错误标签保留语义轻底色；普通标签不增加边框；长标签裁切与 +N 展开保留。文字使用现有 12px/18px 标签角色，主行 13px/20px，密度 44/48px。

A 保留原结构基线；C、D 仅保留早期对照，不作为当前推荐。C 分列曾被指出增加扫视负担；D 的 64px 行高超出现有密度合同。此前限宽版 B 不再作为当前成果。

## 证据与限制

最新 evidence-b/geometry.json 与截图覆盖原 B／当前 B 在相同 1440×900、960×640 窗口下的日志和案例页面，175% 像素密度；另检查 1280×800 的 30 笔长标签、策略浮层、全部标签与 48px 状态。没有页面 JavaScript 错误。

同窗口前后：策略起点、右侧数值位置、主行字号和行高一致。1440px 无横向溢出。960px 仍保留原有横向列表滚动，这是基线布局限制，本轮不靠改窄侧栏、缩字号或重排列隐藏。

日志核心字段来自用户截图，未展开标签为演示占位；案例库是合成数据。筛选和浮层仅用于视觉试验，不提供真实交易处理。HTML 并非原生 Electron 的像素级克隆；macOS 尚未验证。
